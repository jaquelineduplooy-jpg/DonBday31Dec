WHEN I’M SEVENTY — FINAL V20-BASED WEBSITE

1. Unzip and upload index.html plus the assets/ folder to the existing Vercel site.
2. Google Sheets RSVP: create a PRIVATE Google Sheet. Open Extensions > Apps Script; paste GOOGLE_SHEETS_RSVP_APPS_SCRIPT.gs; run setup() to authorise and create the guest list and summary.
3. Deploy > New deployment > Web app. Execute as: Me. Access: Anyone (guests can submit without signing in). Copy the deployment's /exec URL.
4. In index.html replace PASTE_YOUR_GOOGLE_APPS_SCRIPT_EXEC_URL_HERE with that exact URL (also replace in preview.html if using that locally).
5. Redeploy to Vercel and test a Yes RSVP and a No RSVP. Check both the SeventyRSVPs sheet and the automatic Headcount summary. KEEP the Sheet private.

The RSVP page does not secretly record guests until the Apps Script URL is configured. The website does not take payment or collect email addresses.
The site's vinyl picture is supplied as assets/spotify-vinyl-cover.png; updating the Spotify account's own playlist cover must be done separately in Spotify.
The Memory Reel continues to load the existing Google Drive photo feed if available. Until family photos are added/accessible, fallback images are theme placeholders.
No live hosting or Google Sheet connection was performed automatically.
