WHEN I’M SEVENTY — V20: GOOGLE SHEETS RSVP CONNECTION

Target Google Sheet (provided by organiser):
https://docs.google.com/spreadsheets/d/10eqUEZeiPZe_Ap6g9lv0b8bRIRAcQniIEKPB9UVS6Xg/edit

The website form now uses THREE inputs: Name, Number of People, and Yes/No.
The Google Apps Script bundled here is preconfigured with the exact destination Sheet ID.

AUTHORIZE THE CONNECTION — one-time steps for the spreadsheet owner:
1. Open your Google Sheet URL above with an account that has edit access.
2. Click Extensions > Apps Script.
3. Paste GOOGLE_SHEETS_RSVP_APPS_SCRIPT.gs into Code.gs and save.
4. Choose the setup function from the function menu, click Run, and authorize access.
   This adds RSVPs and Headcount tabs without wiping any existing confirmation data.
5. Select Deploy > New deployment > Web app.
   Execute as: Me. Who has access: Anyone. Click Deploy. Grant permission if asked.
6. Copy the Web App URL ending in /exec.
7. In BOTH index.html and preview.html, replace:
   PASTE_YOUR_GOOGLE_APPS_SCRIPT_EXEC_URL_HERE
   with that exact /exec URL.
8. Deploy the website package to Vercel.
9. Test one Yes (two people), and one No (zero people). Confirm entries and
   the running total in the Headcount tab of your original Google Sheet.

IMPORTANT: Until the Google Web App has been deployed and the /exec URL is filled
in, the RSVP form will show that collection has not been connected yet; it does
not pretend to submit successfully. Simply sharing a Google Sheet URL does not
make it possible for anonymous website guests to write into it.
